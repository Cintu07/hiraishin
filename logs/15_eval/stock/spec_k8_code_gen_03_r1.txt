Here's an implementation of a **thread-safe bounded queue** in Rust with `push` and `pop` methods that **block when the queue is full or empty**, respectively. This is achieved using **Rust's standard library concurrency primitives** such as `Arc`, `Mutex`, and `Condvar`.

---

## ✅ Design Overview

- **Bounded Queue**: The queue has a fixed maximum capacity.
- **Thread-safe**: Uses `Arc<Mutex<...>>` to allow multiple threads to access the queue safely.
- **Blocking Operations**:
  - `push` blocks when the queue is full.
  - `pop` blocks when the queue is empty.
- **Condition Variables**: Used to signal when the queue becomes non-full or non-empty.

---

## 🧩 Implementation

```rust
use std::sync::{Arc, Mutex, Condvar};
use std::thread;
use std::time::Duration;

struct BoundedQueue<T> {
    queue: Vec<T>,
    capacity: usize,
    not_full: Condvar,
    not_empty: Condvar,
    lock: Mutex<()>,
}

impl<T> BoundedQueue<T> {
    pub fn new(capacity: usize) -> Self {
        BoundedQueue {
            queue: Vec::with_capacity(capacity),
            capacity,
            not_full: Condvar::new(),
            not_empty: Condvar::new(),
            lock: Mutex::new(()),
        }
    }

    pub fn push(&self, item: T) {
        let mut guard = self.lock.lock().unwrap();
        while self.queue.len() >= self.capacity {
            // Wait until the queue is not full
            guard = self.not_full.wait(guard).unwrap();
        }
        self.queue.push(item);
        self.not_empty.notify_one();
    }

    pub fn pop(&self) -> Option<T> {
        let mut guard = self.lock.lock().unwrap();
        while self.queue.is_empty() {
            // Wait until the queue is not empty
            guard = self.not_empty.wait(guard).unwrap();
        }
        let item = self.queue.remove(0);
        self.not_full.notify_one();
        Some(item)
    }
}

fn main() {
    let queue = Arc::new(BoundedQueue::new(5));
    let queue_clone = Arc::clone(&queue);

    // Producer thread
    thread::spawn(move || {
        for i in 0..10 {
            queue.push(i);
            println!("Produced: {}", i);
            thread::sleep(Duration::from_millis(100));
        }
    });

    // Consumer thread
    thread::spawn(move || {
        for _ in 0..10 {
            if let Some(item) = queue.pop() {
                println!("Consumed: {}", item);
            }
            thread::sleep(Duration::from_millis(150));
        }
    });

    // Wait for threads to finish
    thread::sleep(Duration::from_secs(2));
}
```

---

## 📌 Explanation

- **`BoundedQueue<T>`**:
  - `queue`: The internal vector that holds the items.
  - `capacity`: Maximum number of items the queue can hold.
  - `not_full` and `not_empty`: `Condvar`s used to signal when the queue is not full or not empty.
  - `lock`: A `Mutex` to protect access to the queue.

- **`push`**:
  - Acquires the lock and waits if the queue is full.
  - Adds the item to the queue and notifies the consumer.

- **`pop`**:
  - Acquires the lock and waits if the queue is empty.
  - Removes the first item and notifies the producer.

- **Condition Variables**:
  - `not_full` is used to wake up the producer when space becomes available.
  - `not_empty` is used to wake up the consumer when items become available.

---

## 🧠 Notes

- This implementation is **blocking**, meaning threads will wait until the queue is in a state that allows them to proceed.
- It uses **wait()** and **notify_one()** to avoid busy waiting.
- This is a **classic producer-consumer pattern** with bounded capacity.
