- Parses command-line arguments.
- Loads a model and its vocabulary.
- Tokenizes prompts.
- Performs **prefilling** (initial token generation).
- Performs **decoding** (generating subsequent tokens).

- Outputs results in **JSON format** for each run.

### 2. **`args_t` struct**

```cpp
struct args_t {
    std::string target, draft, out = "harness_out";
    std::vector<std::string> prompts;
    std::vector<int> ks = {2, 4, 8};
    std::vector<float> taus = {0.0f};
    std::vector<int> ngrams = {0};
    int ng_cooldown = 0;
    std::vector<int> pad_verifies = {0};
    std::vector<int> inv_bs = {2, 3, 5, 9};

    bool verify_cost = true, invariance = true, pad_guard = true, draft_probe = false, draft_b2 = true;

```

- **Purpose**: Stores command-line arguments and configuration parameters.
- **Fields**:
  - `target`: Path to the main model file.
  - `draft`: Path to the draft model (used for speculative decoding).
  - `prompts`: List of input prompts.
  - `ks`: List of values for `k` in top-k sampling.
  - `taus`: List of values for `tau` in top-p sampling.
  - `ngrams`: List of n-gram values for repetition penalty.
  - `ng_cooldown`: Cooldown period for n-gram penalty.
  - `pad_verifies`: List of padding verification values.
  - `inv_bs`: List of batch sizes for invariance checks.
  - `n_predict`: Number of tokens to predict.
  - `n_ctx`: Context size.
  - `reps`: Number of repetitions for benchmarking.
  - `verify_cost`: Whether to verify cost.
  - `invariance`: Whether to check batch invariance.
  - `pad_guard`: Whether to enable padding guard.
  - `draft_probe`: Whether to probe the draft model.
  - `draft_b2`: Whether to use batch 2 for draft.

### 3. **`parse_list(const char * s)`**

```cpp
static std::vector<int> parse_list(const char * s) {
    std::vector<int> v;
    std::stringstream ss(s);
    std::string x;
    while (std::getline(ss, x, ',')) v.push_back(std::atoi(x.c_str()));
    return v;
}
```

- **Purpose**: Parses a comma-separated string into a list of integers.
- **Usage**: Used to parse command-line arguments like `--k 2,4,8`.
