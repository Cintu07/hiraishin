Here's a SQL schema for a **small library system** that includes **books**, **members**, and **loans**. Then, I'll provide **three example queries**:

---

## ✅ **SQL Schema**

```sql
CREATE TABLE IF NOT EXISTS Members (
    member_id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL,
    joined_date DATE NOT NULL
);

CREATE TABLE IF NOT EXISTS Books (
    book_id INT PRIMARY KEY AUTO_INCREMENT,
    title VARCHAR(255) NOT NULL,
    author VARCHAR(100) NOT NULL,
    publication_year INT NOT NULL,
    available BOOLEAN DEFAULT TRUE
);

CREATE TABLE IF NOT EXISTS Loans (
    loan_id INT PRIMARY KEY AUTO_INCREMENT,
    member_id INT NOT NULL,
    book_id INT NOT NULL,
    loan_date DATE NOT NULL,
    return_date DATE,
    FOREIGN KEY (member_id) REFERENCES Members(member_id),
    FOREIGN KEY (book_id) REFERENCES Books(book_id)
);
```

---

## 📚 **Example Queries**

### 1. **Overdue Loans**
Find all loans that are overdue (i.e., `return_date` is not set and the current date is past the `loan_date`).

```sql
SELECT *
FROM Loans
WHERE return_date IS NULL
  AND loan_date < CURDATE();
```

---

### 2. **Most Borrowed Books**
Find the book(s) that have been borrowed the most.

```sql
SELECT b.title, COUNT(*) AS borrow_count
FROM Loans l
JOIN Books b ON l.book_id = b.book_id
GROUP BY b.book_id
ORDER BY borrow_count DESC
LIMIT 1;
```

---

### 3. **Members with No Loans**
Find members who have never borrowed a book.

```sql
SELECT m.name, m.email
FROM Members m
WHERE NOT EXISTS (
    SELECT 1
    FROM Loans l
    WHERE l.member_id = m.member_id
);
```

---

## 📌 Notes

- This schema assumes a simple library system with no inventory tracking beyond availability.
- `CURDATE()` is used to get the current date (MySQL syntax).
- You can adapt the queries for other SQL dialects (e.g., PostgreSQL, SQL Server) as needed.
