This project successfully achieved lossless, high-speed speculative decoding of the Qwen3-8B model on an RTX 5060 Laptop GPU, reaching over 100 tokens per second using a custom CUDA implementation and a series of patches that ensure accuracy and efficiency. By addressing key issues in the decoding process, such as kernel selection, memory management, and graph caching, the team enabled real-time, bit-identical decoding that matches the performance of standard greedy decoding, with additional speed boosts from n-gram-based drafting techniques.
