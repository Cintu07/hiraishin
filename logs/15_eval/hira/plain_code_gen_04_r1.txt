Here's a JavaScript function that **debounces another function** and includes a **cancel method**, along with **JSDoc comments** for clarity and documentation:

```javascript
/**
 * Debounces a function so that it is called only after a certain amount of time has passed without being invoked.
 * @param {Function} func - The function to debounce.
 * @param {number} delay - The delay in milliseconds.
 * @returns {Object} An object with the debounced function and a cancel method.
 */
function debounce(func, delay) {
    let timeoutId;

    /**
     * The debounced function.
     * @param {...any} args - Arguments to pass to the original function.
     */
    const debounced = function debounced(...args) {
        clearTimeout(timeoutId);
        timeoutId = setTimeout(() => {
            func.apply(this, args);
        }, delay);
    };

    /**
     * Cancels the pending function call.
     */
    const cancel = function cancel() {
        clearTimeout(timeoutId);
    };

    return {
        debounced,
        cancel
    };
}
```

### ✅ Example Usage:

```javascript
const myFunction = (value) => {
    console.log(`Debounced function called with: ${value}`);
};

const { debounced, cancel } = debounce(myFunction, 500);

debounced("Hello"); // No output immediately
debounced("World"); // No output immediately

// After 500ms, "World" will be logged

cancel(); // Cancels the pending call
```

### 📌 Notes:
- The `debounced` function is called only after the specified `delay` has passed since the last call.
- The `cancel` method stops the function from being called if it's still pending.
- This is useful for scenarios like search input, resizing events, or throttling API calls.
