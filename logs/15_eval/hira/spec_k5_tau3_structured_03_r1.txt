Here's a **JSON object** describing a fictional laptop, followed by a **JSON Schema** that validates it.

---

### ✅ **Fictional Laptop JSON Object**

```json
{
  "brand": "NexTech",
  "model": "X1 Pro",
  "cpu": "Intel Core i9-13900H",
  "gpu": "NVIDIA RTX 4090",
  "ram_gb": 32,
  "storage_gb": 1000,
  "price_usd": 2499,
  "ports": ["USB-C", "HDMI", "Thunderbolt 4", "Ethernet", "USB-A", "Audio Jack"]
}
```

---

### ✅ **JSON Schema for Validation**

```json
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "title": "Fictional Laptop",
  "type": "object",
  "properties": {
    "brand": {
      "type": "string"
    },
    "model": {
      "type": "string"
    },
    "cpu": {
      "type": "string"
    },
    "gpu": {
      "type": "string"
    },
    "ram_gb": {
      "type": "integer"
    },
    "storage_gb": {
      "type": "integer"
    },
    "price_usd": {
      "type": "number"
    },
    "ports": {
      "type": "array",
      "items": {
        "type": "string"
      }
    }
  },
  "required": [
    "brand",
    "model",
    "cpu",
    "gpu",
    "ram_gb",
    "storage_gb",
    "price_usd",
    "ports"
  ],
  "additionalProperties": false
}
```

---

### 📝 Notes:

- The `ports` field is an array of strings representing the types of ports available.
- `ram_gb` and `storage_gb` are integers (in GB).
- `price_usd` is a number (can be a float if needed).
- The schema ensures that all required fields are present and that no extra fields are allowed.
