A **CPU cache hierarchy** (L1, L2, L3) is a system of small, fast memory layers that sit between the CPU and main memory (RAM). The goal of the cache hierarchy is to **reduce the time it takes for the CPU to access data** by storing frequently used data in faster, smaller memory layers.

---

## 🔍 **How the CPU Cache Hierarchy Works**

The cache hierarchy is structured in **levels**, with each level being **larger but slower** than the previous one:

| Level | Size | Speed | Latency | Purpose |
|-------|------|-------|---------|---------|
| **L1** | 8–64 KB | Fastest | ~1–3 cycles | Fastest access, holds most frequently used data |
| **L2** | 256 KB–8 MB | Faster than RAM | ~10–20 cycles | Next level of cache, holds data not in L1 |
| **L3** | 8 MB–32 MB | Slower than L2 | ~40–100 cycles | Shared among all cores, holds data not in L1 or L2 |
| **RAM** | 8 GB–1 TB |
